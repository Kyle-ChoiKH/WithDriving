# 시연 영상 구성

영상: [`media/demo.mp4`](media/demo.mp4) (3분 17초, 1920 × 1080, 소리 없음)

**Pleos Connect Emulator v2.1.0에 release APK를 설치해 녹화한 화면만 썼습니다.** 화면 오른쪽의 글은 편집으로 넣은 설명이고, 앱 화면 안의 "데모" 자막은 앱이 직접 띄우는 것입니다.

| 순서 | 내용 | 무엇으로 찍었나 |
|---|---|---|
| 1 | 첫 실행 소개 카드 → 꼬마차와 친구들: 기어 D, 출발, 깜빡이, 풍량과 온도, 브레이크, 음악, 별과 급제동, 비와 전조등, 도착, 오늘의 드라이브 | 앱 안의 데모 드라이브 "브루미 하이라이트" (시뮬레이터 신호) |
| 2 | 실제 차량 신호: 풍량 7, 설정 온도 18°C, 전조등과 와이퍼, 왼쪽 방향지시등, 운전석 문 | **Virtual Console로 값을 바꿔 Pleos Vehicle SDK 콜백으로 반응** (데모 아님, 기어 P) |
| 3 | 테마 고르기 → 테마 11종: 오토매틱 시계, 엔진룸, 로봇 격납고, 아쿠아리움, 플라즈마, 오르골, 유리병 정원, 작은 태양계, 보물지도, 종이 팝업북, 도트 월드 | 테마 화면의 "데모로 보기" (Lv.5 버전) |
| 4 | 직접 조작해 보기: 전조등, 와이퍼 버튼 | 앱 안의 직접 조작 데모 |
| 5 | 안전운전 등급 화면 | 등급 탭 |
| 6 | 마무리: 사용한 SDK 5종, 안전 원칙 | 편집 자막 |

## 알아 둘 점

- 주행 중 장면은 모두 앱 안의 데모 드라이브입니다. 에뮬레이터는 adb로 설치한 앱을 차량이 주행 상태(D단)일 때 가리기 때문입니다(README 1-2b 참고). 실제 신호 장면은 그래서 P단에서 찍었습니다.
- 에뮬레이터의 시계가 오전이라 장면은 낮입니다. 밤 장면은 전조등 신호로 바뀐 것입니다.
- 영상에는 실명, 계정, 연락처가 나오지 않습니다.

## 다시 찍으려면

1. 에뮬레이터를 켜고 release APK를 설치합니다: `adb install -r apk/Kyle_WithDriving_release.apk`
2. 호스트에서 녹화합니다: `adb emu screenrecord start --size 1920x1080 --fps 60 <파일>.webm`, 끝나면 `adb emu screenrecord stop`. 기기 안의 `screenrecord`보다 프레임이 잘 나옵니다(2560 × 1440으로 찍으면 초당 13장 정도).
3. Virtual Console은 에뮬레이터의 8088 포트에 있습니다: `adb forward tcp:8088 tcp:8088` 후 브라우저에서 `http://localhost:8088`.
