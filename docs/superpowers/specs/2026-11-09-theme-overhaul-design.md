# 테마 전면 개편 + 안전운전 등급 — 설계 (2026-11-09)

v1.6.0-contest(versionCode 7) 위에서 작업한다. 목표 버전은 **v1.7.0-contest(versionCode 8)**이며, 접수 마감은 2026-11-15(일) 23:59.

## 1. 의도

- **테마마다 한눈에 구별되는 확실한 성격:** 지금은 여러 테마가 "깔끔한 일러스트"라는 같은 결로 보인다. 각 테마는 재질·빛·색·글꼴·움직임 중 적어도 둘에서 다른 테마와 확실히 달라야 한다.
- **실물 테마는 "실사틱"하게:** 진짜 같은 빛, 재질, 그림자를 쓰되 모양과 세부는 절제한다. 기준은 "잘 만든 제품 일러스트"다. 과하게 재현해서 AI 렌더 티가 나면 실패다(사용자 명시).
- **안전운전 = 내 테마의 업그레이드:**
  - 테마 12개는 처음부터 모두 쓸 수 있다.
  - 안전운전으로 등급이 한 단계 오를 때마다 **모든 테마가 그 테마다운 방식으로 한 단계씩 업그레이드**된다(5등급 × 12테마 = 60가지 모습).
  - 심사 기준(차량특화성·사업성/리텐션)과 바로 이어진다.

## 3. 지켜야 할 것 (기존 규칙 유지)

- 차는 **읽기만** 한다. 테마 코드는 차량 제공자에 닿지 않는다.
- 번쩍임은 영역당 초당 3회 이하(FlashGuard)로, 밝기 급변은 Entrances·LuminanceFlashTest 규칙을 따른다. 플라즈마도 번개처럼 터지는 연출은 금지하고, 가닥 밝기의 흔들림은 ±15% 이내의 부드러운 잡음으로 한다.
- 진단값·경고등 그림과 "점검·경고·고장·℃·압력" 같은 단어는 쓰지 않는다(FORBIDDEN_WORDS). 엔진 수치는 모두 "추정"이라고 표시한다.
- 주행 중 장면 안 글자는 24sp 이상만 쓴다. 앱 버튼은 왼쪽 위·오른쪽 아래 두 구석만(ChromeZones) 쓴다.
- 차분 모드, 움직임 줄이기, 안전 경고 시 멈춤·어둡게(SafetyFreeze)를 지킨다. 과속은 절대 보상하지 않는다(110 km/h 이상에서 연출 상한).
- **IP:** 실존 캐릭터·브랜드·제품 디자인을 쓰지 않는다.
  - 시계: 까르띠에 등 브랜드 케이스 형상(탱크·산토스 등)과 로마 숫자+청색 카보숑 조합을 쓰지 않는다.
  - 로봇: 건담 고유 요소(V자 뿔, 입 모양 페이스 마스크, 흰·파랑·빨강·노랑 배색, 모노아이, 빔 무기·총기)를 쓰지 않는다.
  - 상표 "Nixie"는 쓰지 않는다.
- 그림은 모두 코드(Compose Canvas)로 그린다. 사진·외부 이미지는 쓰지 않고, 질감(주물 표면, 나뭇결, 브러시드 금속, 모래 빛무늬)은 코드로 만들어 LayerSlot에 캐시한다(공용 48 MB 예산).
- 성능 목표: 주행 장면 그리기 6 ms 안팎(에뮬레이터에서 60 fps 유지). 최고 단계도 이 목표를 지킨다.

## 4. 등급 시스템

### 4.1 점수와 등급

- **주행 점수(기존 유지):** `SmoothnessScore` = 100 − 급가속×4 − 급제동×6 − 110 km/h 초과 1분당 2.
- **최근 안전 점수:** 데모가 아닌 최근 10회 주행 점수의 거리 가중 평균. 주행이 없으면 "—".
- **안전 거리:** 점수 70 이상인 실제 주행 거리의 합(기존 `Bond.careKm`과 같다).
- **등급 5단계:** 한 번 오른 등급은 내려가지 않고 최고 기록으로 저장한다(`settings.gradeReached`). "다이어리 초기화"를 하면 함께 1로 돌아간다.

| 등급 | 이름 | 조건 |
|---|---|---|
| 1 | 브론즈 | 시작 |
| 2 | 실버 | 안전 거리 10 km, 최근 점수 75 이상 |
| 3 | 골드 | 30 km, 80 이상 |
| 4 | 플래티넘 | 60 km, 85 이상 |
| 5 | 다이아몬드 | 100 km, 90 이상 |

- 기존 "우정 레벨"(`Bond`)은 등급으로 바꾼다. 홈 배지 예시: `골드 · 별 42개 · 다음 등급까지 12.3 km · 점수 85 필요`.

### 4.2 업그레이드 규칙

- 테마 12개는 처음부터 모두 열려 있다. 잠긴 테마는 없다.
- 테마마다 **업그레이드 단계 1~5**가 있고, 등급 n이 되면 모든 테마의 단계 1~n이 열린다(`model = 0..4`, 단계 = model + 1).
- **사다리 원칙:** 각 단계는 앞 단계 위에 그 테마다운 무언가가 **눈에 보이게 더해지거나 바뀐다**. 재질 승급, 부품 추가, 형태 변화, 무대 확장이 그 방법이다. 단계마다 "무엇이 새로 생겼나"를 한 줄로 말할 수 있어야 한다. 그래야 사용자가 다음 등급을 기대하게 되고, 화가 코드도 단계별 레이어로 쌓아 갈 수 있다.
- 기본값은 열린 가장 높은 단계다. 모델 시트에서 낮은 단계로 되돌려 쓸 수 있고, 테마마다 `model.<THEME>`로 저장한다.
- **꼬마차의 옷:** 기존 옷 5종(목도리·고글·비니·우비·케이블 올가미)이 등급 1~5에 하나씩 열린다(기존 레벨 매핑 그대로). 꼬마차의 업그레이드 단계(길·꼬마차)와는 별개로 옷장에서 입힌다.

### 4.3 화면

- **등급 탭**(옛 옷장 자리, 주차 중에만 열림):
  1. 현재 등급 메달과 이름, 최근 안전 점수(큰 숫자), 안전 거리
  2. 다음 등급 조건 두 줄(거리·점수)의 진행 막대
  3. 점수 계산 설명 한 줄
  4. **다음 업그레이드 미리 보기:** 지금 테마의 다음 단계 그림 한 장 + "플래티넘이 되면: 토노 스켈레톤 케이스"
  5. 등급별 업그레이드 목록: 5줄, 각 줄에 그 등급의 지금 테마 단계 이름과 꼬마차 옷
  6. 꼬마차 옷장: 기존 옷 입히기 카드를 그대로 옮긴다
- **테마 탭**(옛 친구 탭) 갤러리 카드: 잠금 없이 모두 고를 수 있다. 카드 모서리에 단계 태그("Lv.3")를 붙인다.
- **모델 시트(칩 "업그레이드 · Lv.3 쿠션 케이스"):** 5줄. 열리지 않은 단계는 "플래티넘 등급에 열려요"로 표시하고, 무대에서 미리 볼 수는 있지만 적용되지는 않는다.
- **데모 드라이브와 쇼케이스는 등급과 상관없이 재생된다.** 시나리오 JSON에 선택 필드 `"model": 0~4`를 추가해, 쇼케이스는 최고 단계(4)로 보여 준다(심사·시연용).
- 개발자 패널에 "모든 등급 미리 열기(저장 안 함)"를 둔다. 디버그 빌드 전용이며, 기존 설정 화면의 숨은 탭으로도 열린다.
- 주행 중에는 등급 탭·갤러리·시트를 열지 않는다(기존 규칙).

## 5. 테마별 설계 — 성격과 업그레이드 사다리

모든 테마에 공통으로: `SceneOptions.model: Int`(0~4)를 화가가 `f.options.model`로 읽는다. KART·CALIBRE·ENGINE은 각자의 Scene이 같은 값을 받는다. 기존 신호 대응(차속·깜빡이·브레이크·와이퍼·공조·별·콤보·km)은 모든 단계에서 유지한다.

"실사틱" 화법 공통 규칙:
- 형태마다 빛 방향 하나로 음영 그라디언트를 주고, 반사광은 1~2줄만 넣는다.
- 바닥 접지 그림자는 부드럽게, 틈새에는 가벼운 차폐 그림자를 넣는다.
- 질감은 캐시된 저대비 잡음으로 표현한다.
- 쓰지 않는 것: 고대비 잔무늬, 의미 없는 장식 부품(그리블), 과포화 글로우, 플라스틱 광택.

각 표의 "단계 이름"은 화면(모델 시트·등급 탭)에 그대로 쓴다.

### 5.1 오토매틱 시계 (CALIBRE) — 실사틱, 밝게

- **성격:** 밝은 시계 공방 진열대에서 찍은 접사 사진.
- **배경:** 아이보리에서 웜그레이로 가는 무광 바닥(#EEE8DF → #D6CFC4, 가장자리 비네트)에 위쪽 부드러운 확산광. 시계 아래에는 부드러운 접지 그림자. 가장자리에 흐리게 날아간 소품(루페, 핀셋)을 저대비로 둘 수 있다.
- **밤:** 따뜻한 스탠드 조명의 중간 밝기. 검은 배경으로 돌아가지 않는다.
- **글자:** 아래 글줄은 밝은 바탕에 진한 회색(대비 4.5:1 이상).
- **재질:** 강철·로듐·사파이어 유리 반사를 또렷하게. 기본 인상은 흰 바탕 + 강철 + 파란 나사(오르골의 황동과 겹치지 않게).
- 마감 5종 선택은 그대로 둔다(단계와 독립).

| 단계 | 이름 | 새로 생기는 것 |
|---|---|---|
| 1 | VR-01 스틸 | 40 mm 원형 스틸 케이스, 무광 브리지, 시스루 백 |
| 2 | VR-01 데코 | 브리지에 제네바 줄무늬, 바닥판 페를라주, 블루 스크루 |
| 3 | VR-01 쿠션 | 둥근 사각 쿠션 케이스, 기요셰 문자판, 투각 로터 |
| 4 | VR-01 토노 스켈레톤 | 술통형 토노 케이스, 투각 브리지로 기어가 보임 |
| 5 | VR-01 투르비용 | 6시 플라잉 투르비용(1분 1바퀴), 금 샤통에 박힌 보석, 스켈레톤 문자판 |

### 5.2 엔진룸 (ENGINE) — 실사틱, 공학 감성

- **성격:** 전시장의 실제 절개(컷어웨이) 엔진 + 엔지니어용 계측 화면.
- **배경:** 흑연색 스튜디오(#15181B → #23272B), 왼쪽 위 차가운 주광 + 오른쪽 따뜻한 윤곽광. 낮에도 어둡게 하되 금속은 밝게 빛난다.
- **재질:**
  - 알루미늄 주물 블록: 무광, 저대비 모래 반점
  - 가공면: 더 밝고 가는 공구 자국
  - 단조 크랭크: 새틴 강철
  - 그 밖: 크롬 밸브 스템, 청동 베어링, 검은 고무 벨트, 편조 호스
  - 절단면: 신호 빨강(#C2281F) + 가는 해칭
  - 섬프: 오일 막 광택
- **계측 화면:** 실제 시뮬레이션 값(EngineMechanics)을 그리고, 모든 수치에 "추정"을 붙인다. 단계가 오를수록 항목이 늘어난다(아래 표).
- **글꼴:** 숫자는 고정폭(시스템 monospace), 표제는 좁은 산세리프(시스템 sans-serif-condensed). 크기 3단계, 정렬선을 맞추고, 주행 중 24sp 규칙을 지킨다.
- 슬로모션 한도(크랭크 최대 1.4바퀴/초, 불꽃 초당 3회 이하) 유지.

| 단계 | 이름 | 엔진에 새로 생기는 것 | 계측 화면 |
|---|---|---|---|
| 1 | VE-4 SOHC | 주철 블록, 캠 하나, 흡기 매니폴드 | 크랭크각·rpm |
| 2 | VE-4 DOHC | 알루미늄 블록, 캠 둘 + 가변 밸브 타이밍 페이저 | + 실린더 행정 띠(1-3-4-2) |
| 3 | VE-4T 터보 | 터보차저·인터쿨러·블로오프 밸브 | + 부스트, 밸브 리프트 곡선 |
| 4 | VE-4T 직분사 | 직분사 인젝터, 단조 피스톤, 편조 호스 | + 토크·출력 곡선 위 현재 점 |
| 5 | VE-4R 레이스 | 개별 스로틀 나팔관, 드라이 섬프, 티타늄 커넥팅 로드, 카본 덮개, 금색 차열판 | 풀 계측(점화 시기 포함) |

- **전기 모터(EV) 쪽 사다리:**
  1. 단일 모터
  2. 오일 냉각 재킷
  3. 구리 헤어핀 고정자
  4. 이중 모터(앞·뒤)
  5. 카본 슬리브 로터 + 은도금 버스바

### 5.3 오르골 (MUSIC_BOX) — 실사틱, 고급

- **성격:** 따뜻한 스탠드 조명 아래 열린 원목 오르골.
- **배경:** 짙은 따뜻한 갈색 방에 조명이 둥글게 떨어진다. 완전 검정은 쓰지 않는다.
- **표현:**
  - 나뭇결은 코드로 만든 결 + 래커 반사 띠
  - 황동 실린더의 강철 핀이 돌며 빛을 받는다
  - 빗살은 튕긴 뒤 감쇠 진동한다
  - 공기 조속기가 빠르게 돌고, 감을 때 태엽 키가 돈다
  - 상자 앞 명판은 고전 세리프 대문자
- 기존 작곡기·핀 실린더 로직(MusicBoxSim·Composer)은 유지한다.

### 5.11 신규: 플라즈마 (PLASMA) — 실사틱, 분류 "기계"

- **성격:** 어두운 실험 책상 위 고전압 장치. 보랏빛 플라즈마와 진공관의 호박빛이 주인공이다.
- **배경:** 짙은 청흑(#0E1016 → #1A1C26), 책상 상판의 은은한 반사.
- **주인공:** 검은 받침 위 유리구 플라즈마 볼. 중심 전극에서 유리면까지 보라·자홍 가닥이 뻗고, 가닥 중심은 흰빛, 유리 안쪽은 은은하게 빛난다. 가닥은 노이즈로 천천히 구불거린다.
- **차 신호:**

| 신호 | 반응 |
|---|---|
| 차속 | 가닥 수 4~14, 일렁임 속도(110 km/h에서 상한) |
| 가속 | 진공관 필라멘트 밝기(3단계부터) |
| 깜빡이 | 손을 댄 것처럼 가닥이 그쪽 유리면으로 모이고, 닿은 점이 밝아짐(FlashGuard) |
| 브레이크 | 가닥이 짧아지며 중심으로 움츠러들고 어두워짐 |
| 공조 풍량 | 오실로스코프 진폭(4단계부터) |
| 와이퍼(비) | 유리구 표면 물방울 |
| 별 | 유리 표면에 빛점 하나가 잠시 머묾 |
| 콤보 | 가닥 전체가 천천히 한 바퀴 회전 |
| 1 km | 숫자관 자리 올림(2단계부터), 야곱의 사다리 호 상승(5단계) |
| 안전 경고 | 가닥이 멈추고 어두워짐 |

- **안전:** 가닥 밝기 흔들림 ±15% 이내, 섬광·번개 없음, 모든 반짝임은 FlashGuard를 거친다.

| 단계 | 이름 | 새로 생기는 것 |
|---|---|---|
| 1 | 플라즈마 볼 | 유리구 + 받침 |
| 2 | 네온 계수기 | 오렌지 네온 숫자관 5자리 주행 거리계 |
| 3 | 진공관 앰프 | 진공관 2개(호박색 필라멘트, 회색 플레이트, 은색 게터) |
| 4 | 오실로스코프 | 작은 원형 화면의 사인파(주파수 ∝ 차속) |
| 5 | 야곱의 사다리 | 두 전극 사이 호가 1 km마다 아래에서 위로 천천히 올라가 부드럽게 사라짐 |

### 5.12 신규: 로봇 격납고 (HANGAR) — 실사틱, 분류 "기계"

- **성격:** 조명이 켜진 거대 로봇 격납고. 내 로봇이 달린 거리만큼 조립된다.
- **배경:** 콘크리트 바닥(도색 표시선, 젖으면 반사), 강철 갠트리와 캣워크, 천장 크레인, 사선 안전 줄무늬, 나트륨·LED 조명, 작은 작업자 실루엣(크기 비교용). 밤에는 투광등이 켜진다.
- **로봇 공통 골격 "HX"(오리지널):**
  - 약 18 m 산업·구조용 프레임
  - 머리: 가로 띠 하나인 바이저 센서
  - 어깨: 둥근 사각 블록 위 경광등
  - 가슴: 동력로 창
  - 등: 방열 핀·냉각 팬
  - 관절: 무릎·발목 유압 실린더가 보임
  - 무기 없음, 건담 고유 요소 없음(3절)
  - 단계마다 같은 골격 위에 장갑·장비·도색을 바꾼다.
- **조립 진행:**
  - 실제 주행 거리 30 km에 걸쳐 0 → 100%. 빨리 달려도 더 빨라지지 않는다.
  - 순서: 골격 → 내부 기계(액추에이터·배선) → 장갑 → 도색 → 마킹
  - `theme.HANGAR.state`로 저장하고, 데모 중에는 늘지 않는다.
  - 완성 후에는 기동 점검 대기 동작을 하고, 다음 30 km부터 2호기 조립을 시작한다.
- **차 신호:**

| 신호 | 반응 |
|---|---|
| 차속 | 동력로 빛·냉각 팬 회전(110 km/h 상한) |
| 가속 | 등 방열구 증기 |
| 깜빡이 | 그쪽 어깨 경광등 + 머리가 살짝 그쪽으로 |
| 브레이크 | 무릎 유압이 살짝 눌림 |
| 급제동 | 갠트리 고정 클램프가 물리고 호박색 회전등(경고라는 글자 없음) |
| 와이퍼 | 격납고 문밖 비, 바닥 젖음 |
| 헤드라이트 | 바이저가 밝아짐 |
| 공조 | 환기 팬 |
| 별 | 크레인이 작은 부품 하나를 장착(진행 표시) |
| 1 km | 장갑판 하나를 들어 올림 |
| 도착 | 손 흔들기 |
| 주차 | 정비 대기, 작업자 이동 |

| 단계 | 이름 | 새로 생기는 것 |
|---|---|---|
| 1 | HX-1 작업형 | 뭉툭한 장갑, 집게 손, 흑연 + 신호 주황 |
| 2 | HX-2 정비형 | 어깨 작업등, 공구 팔 하나, 오프화이트 패널 |
| 3 | HX-3 구조형 | 구조 윈치, 탐조등, 주황·흰 구조 도색 |
| 4 | HX-4 극지형 | 넓은 설상 발, 방한 장갑 패널, 회백 위장 무늬 |
| 5 | HX-5 탐사형 | 날렵한 장갑, 금빛 바이저, 등 자세 제어 분사구(은은한 청색, 불꽃 없음) |

- 각 화가 내부 구조(단계별 레이어 분할, 캐시 키에 단계 포함, 잡음 생성 방법)
- 색값 미세 조정, 소품의 정확한 형태
- 신호 대응의 세부 타이밍(위 표의 범위 안)
- 단, 그린 결과는 반드시 스냅샷으로 직접 보고 "실사틱하되 과하지 않은가", "단계마다 무엇이 새로 생겼는지 한눈에 보이는가"를 판단한다.
