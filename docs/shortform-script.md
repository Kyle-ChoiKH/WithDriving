# 숏폼 대본 (D6) — 45초, 9:16 세로 (Instagram 릴스 / YouTube Shorts)

**만든 영상:** Pleos Connect 에뮬레이터 화면만 쓴 50초 세로 영상(1080 × 1920)을 따로 만들었습니다. 아래 대본에서 실제 차 안 촬영이 들어가는 장면(Spot, 손 조작)은 빼고, 에뮬레이터 장면과 자막으로만 구성했습니다. 영상 파일은 저장소에 넣지 않았습니다.

선택 참여, 본상 가산점 없음. 특별상(50만 원, 1팀)은 본상과 별도로 심사합니다.
구성은 공식 안내의 Spot → Solve → Scene을 따릅니다. 앱 화면은 가로(16:9)이므로 세로 영상에서는 위아래로 나눠 씁니다.

| 시간 | 단계 | 화면 (세로) | 자막 |
|---|---|---|---|
| 0–3s | 훅 | 꼬마차에 폴짝 올라타는 브루미 (화면 가득 확대) | 내가 운전하면… 얘도 운전한다? |
| 3–10s | **Spot** | 혼자 막히는 출근길 (차창 밖 정체, 핸들만 보이게. 얼굴·번호판 없음) | 매일 같은 길, 혼자 하는 출근길 |
| 10–25s | **Solve** | 화면 분할: 위는 손으로 브레이크·깜빡이·풍량 다이얼(정차 상태), 아래는 에뮬레이터의 브루미 (브레이크등, 깜빡이 표지판, 후~ 바람) | 브레이크도, 깜빡이도, 에어컨도 같이 |
| 25–38s | **Scene** | 에뮬레이터: 별이 날아와 쏙 → 바닷가 길 → 비 오는 밤 우비 → 결승선 축하 점프 → "오늘의 드라이브" 카드 | 부드럽게 달리면 별이 모이고, 풍경이 바뀌어요 |
| 38–45s | 엔딩 | 꼬마차에서 내려 손 흔드는 브루미 + 앱 이름 | 차 안의 작은 친구, 브루미 |

`docs/media/vroomi_drive.gif`와 `docs/screenshots/`의 장면을 썸네일·중간 컷으로 쓸 수 있습니다.

## 게시 문구 예시

```
운전할 때 옆에서 같이 운전해 주는 친구가 있다면? 🚗💨
브레이크를 밟으면 브레이크등, 깜빡이를 켜면 깜빡! 부드럽게 달리면 별이 모이는 차량용 앱 "브루미"
#HMG차량용앱개발공모전 #PleosAppMarket #HMG앱공모전
```

- 해시태그는 2~3개, `#HMG차량용앱개발공모전` 필수.
- 개인 또는 팀 계정의 Instagram 릴스 또는 YouTube Shorts에 올리고, 링크를 접수양식 8번에 적습니다.

## 유의사항

- 사람 얼굴, 차량 번호판, 위치를 알 수 있는 간판이 나오지 않게 찍습니다(초상권·개인정보).
- 음원은 플랫폼 제공 라이선스 음원 또는 저작권 없는 음원만 씁니다. 초상권·저작권 문제의 책임은 응모자에게 있습니다.
- 실제 주행 중 촬영 금지. 정차 상태 또는 에뮬레이터 화면만 사용합니다.
- 영상은 현대자동차그룹 행사 시상식에서 사용될 수 있습니다.
