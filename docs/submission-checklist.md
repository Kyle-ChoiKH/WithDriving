### A-2. 테마 팩 (7종) 확인
- [ ] 친구 탭에서 분류별 테마 카드 11개가 보이고, 고른 카드만 움직인다
- [ ] 데모 드라이브의 쇼케이스 7개(오르골·유리병 정원·보물지도·아쿠아리움·궤도·구슬 장치·종이 팝업북)가 끝까지 재생되고, 끝나면 원래 테마로 돌아온다
- [ ] **실기기/에뮬레이터 확인**: 각 테마의 프레임 시간(개발자 패널의 프레임 오버레이)이 6ms 안팎인지
- [ ] **실기기 확인**: "테마 소리"를 켰을 때 Pleos의 오디오 포커스 동작 (길안내 음성·통화·다른 음악 앱과 함께)
- [ ] **실기기 확인**: 보물지도의 FusedLocation 길 그리기, 위치가 없을 때 "그림 지도"로 바뀌는지
- [ ] 유리병 정원: 앱을 다시 켜도 성장이 이어지는지

### A-3. 도트 월드 확인
- [ ] 친구 탭 "놀이"에 도트 월드 카드가 있고, 고른 친구가 꼬마차를 탄다
- [ ] 데모 드라이브의 **도트 월드 쇼케이스 (1분 40초)**가 끝까지 재생되고, 끝나면 원래 테마로 돌아온다
- [ ] **실기기/에뮬레이터 확인**: 1920 × 720에서 4배로 또렷한지(번짐 없음), 프레임 시간이 6ms 안팎인지
- [ ] **실기기 확인**: "테마 소리"를 켰을 때 칩튠이 미디어 소리로 나오고, 길안내 음성 때 줄어드는지
- [ ] 주차 중 친구를 누르면 깡충 뛰고, 주행 중에는 반응하지 않는다
- [ ] 안전 경고(안전벨트 등)가 뜨면 도트 월드가 오른쪽 위 구석으로 물러나 멈추고 어두워진다 (`pixel_safety_freeze.png`와 같은지)

### A-4. 인터페이스와 테마 전환 확인
- [ ] 친구 탭(갤러리)에서 창을 누르면 무대로 커지고, 좌우로 넘기기·화살표·아래로 당겨 닫기가 된다. "이 테마로 달리기"를 누르면 무대가 그대로 홈이 된다
- [ ] **실기기 확인**: API 31 이상에서 반투명 재질의 흐림을 켠 상태로 60fps가 유지되는지 (개발자 패널 "프레임 시간 표시"의 passage 줄, 전환 중 UI 작업 10ms 이하). Pleos GPU의 흐림 비용
- [ ] **실기기 확인**: 진동(카드 선택·적용)이 주차 중에만 나고, 진동 장치가 없으면 아무 일도 없는지
- [ ] 앱을 다시 켤 때 첫 화면의 밤색에서 지난 테마의 배경색으로 단차 없이 바뀌는지
- [ ] 개발자 옵션의 애니메이션 배율을 0으로 두면 모든 전환이 교차(0.2초, 밝기 차이가 큰 테마 사이는 0.7초)로 바뀌는지, 0.5배면 두 배 빨라지는지
- [ ] 주행이 시작되면 칩과 큰 버튼이 미끄러지지 않고 제자리에서 나타나는지, 주행 중 갤러리·무대·시트가 열리지 않는지
- [ ] TalkBack으로 갤러리 카드·무대 버튼·화살표·닫기가 읽히는지
- [ ] **실기기 확인**: Pleos의 Android API 레벨 (31 미만이면 흐림 없는 재질로 표시됨)
