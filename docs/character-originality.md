# 브루미(Vroomi) 캐릭터 독창성 검토

공모전 유의사항: 제3자의 초상권·저작권·디자인권을 침해하면 심사에서 제외되고, 수상 후에도 수상이 취소되며 상금을 전액 환수합니다.
처음 아이디어는 "피카츄 같은 친구가 화면에서 같이 뛰는 느낌"이었습니다. 하지만 특정 캐릭터를 쓰거나 닮게 만들지 않고, 차의 바람과 배터리에서 태어난 오리지널 캐릭터로 새로 설계했습니다.

## 1. 설정

- 종족: "바람불씨(breeze-spark)". 차의 송풍구 바람과 배터리의 웅웅거림이 만나는 곳에서 태어나 대시보드 안에 산다.
- 성격: 밝고 용감하고 약간 과장된 리액션. 잔소리하지 않는다. 부드러운 운전을 축하하고, 거친 운전에는 꾸중 대신 어지러운 척(코믹)을 한다.
- 이름: 브루미(Vroomi), 자동차 소리 "부릉(vroom)"에서 따옴.

## 2. 형태 (코드로 그리는 파라미터)

| 부위 | 브루미 |
|---|---|
| 몸 | 서 있는 달걀형(너비:높이 ≈ 1:1.15), 민트 틸 `#3CC8B4`, 크림색 배 `#FFF4DC`, 짙은 틸 외곽선 `#0E5A51` |
| 머리 위 | 짧고 둥근 **나뭇잎 모양 돛 2개**. 바람과 속도에 비례해 펄럭이고 뒤로 흩날림. 주차 중에는 축 처짐 (대표 특징) |
| 등 | 작은 **소용돌이 프로펠러 깃털**. 속도에 따라 빨리 돔 (꼬리 없음) |
| 눈 | 크고 둥근 짙은 눈 + 흰 하이라이트 1개 |
| 볼 | **볼 동그라미 없음**. 기쁘거나 따뜻할 때만 25% 투명도의 옅은 타원 홍조 |
| 팔다리 | 손가락 없는 벙어리장갑 모양 짧은 팔, 호박색 발바닥 `#F2A93B`(달릴 때 은은하게 빛남) |

## 4. 실루엣 비교 (검은색으로 채웠을 때)

| 토토로 | 토토로: 큰 몸집, 뾰족 귀, 넓은 배 무늬. 브루미: 작은 달걀형, 둥근 돛, 귀 없음 |

## 5. 꼬마차와 배경

브루미가 주행 중에 타는 꼬마 전기차와 화면 속 길도 같은 기준으로 검토했습니다.

| 비교 대상 | 차이 |
|---|---|
| 실제 차량 모델·브랜드 | 특정 차종을 본뜨지 않은 둥근 오픈카 형태. 엠블럼 자리에는 브루미의 새싹 표시만 있음. 현대·기아·제네시스 및 타사 로고·그릴·램프 디자인 요소 없음 |
| 얼굴 있는 자동차 캐릭터 (예: 꼬마버스 타요, 영화 Cars) | 꼬마차에는 눈·입이 없음. 표정은 브루미만 가짐 |
| 카트 레이싱 게임 (예: 마리오 카트) | 경주·상대 차·아이템 상자·무기 없음. 별은 흔한 다섯 꼭짓점 별 모양이며 "무적" 같은 게임 규칙이 없음. 부드러운 운전 거리만 나타냄 |
| 배경 | 도시·가로수길·들판·바닷가·산길을 단순한 도형으로 그림. 실제 건물·지명·간판·랜드마크 없음 |

## 6. 같이 탈 친구 14종 (브루미 외)

사용자는 처음에 치이카와, 뽀로로, 피카츄, 건담 같은 테마를 원했습니다. 이 캐릭터들은 각 권리사가 저작권·상표권을 가지고 있어 만들지 않았습니다. 대신 **사물·동물의 분위기만** 빌린 오리지널 친구를 만들고, 비교 대상이 될 수 있는 기존 캐릭터의 특징을 하나씩 피했습니다.

| 친구 | 피한 기존 캐릭터 / 특징 | 브루미 친구의 형태 |
|---|---|---|
| 쑥떡이 | 치이카와(흰 몸, 곰 같은 둥근 귀, 점 홍조), 기타 찹쌀떡 캐릭터 | 연두색 쑥떡 반구, 귀 없음, 머리 위 쑥잎 하나, 콩고물 점 |
| 얼음콩 | 뽀로로(비행 모자·고글·안경), 펭수(대형, 헤드폰), 핑구(점토 질감) | 남색 꼬마 펭귄, 머리 장식 없음, 곱슬 깃털 하나, 이름에 "펭" 없음 |
| 뭉게 | 기존 구름 캐릭터의 로고·표정 | 둥근 구름 5개를 겹친 몸 + 브루미와 같은 눈 |
| 도톨이 | 도토리 모티프 캐릭터의 고유 의상 | 단순한 도토리 모자와 몸, 브루미와 같은 눈 |
| 너트 | 건담 등 메카(V자 뿔, 삼색 장갑, 인간형 장갑), 베이맥스(흰 둥근 몸, 점과 선 얼굴), 월-E(쌍안경 눈, 무한궤도) | 둥근 사각형 강철 몸, 검은 바이저 화면에 하늘색 LED 눈, 안테나 하나 |
| 초침이·바늘이·나침이 | 실제 시계·계기판·나침반 브랜드 (로고, 왕관 문양, 다이얼 글자) | 글자·로고 없는 문자판, 크라운은 태엽 손잡이 모양 |
| 피스톤·부스트 | 실제 엔진·터보 제조사 로고, 영화 "터보"(달팽이 경주) | 일반적인 엔진 블록과 압축기 하우징 형태, 달팽이 요소 없음 |
| 톱니·태엽이·오르골·필라 | 특정 장난감·전구 제품 디자인 | 일반 톱니, 양철 태엽 장난감, 나무 상자, 전구의 단순 도형 |
| 증기기관차 | 토마스와 친구들(얼굴 달린 기관차) | 만들지 않음 |

- 15종 모두 같은 눈 모양(크고 둥근 눈 + 흰 하이라이트)을 써서 "브루미 친구들"로 묶이고, 기존 캐릭터의 눈 모양을 따르지 않습니다.
- 대사와 이름에 기존 캐릭터의 이름이나 말버릇을 쓰지 않습니다.

## 7. 칼리버 테마 (기계식 시계)

시계는 브랜드 요소가 강한 분야라, 칼리버 테마는 **어떤 시계 브랜드나 실제 무브먼트도 따르지 않도록** 만들었습니다.

| 피한 것 | 칼리버 VR-01의 처리 |
|---|---|
| 브랜드·제조사 이름, 로고, 엠블럼(왕관, 십자가, 닻, 방패, 별 등) | 각인은 `CALIBRE VR-01`, `AUTOMATIC`, `28 800 A/h`, `72H`, `ADJUSTED TO YOUR DRIVE` 같은 모델 표기뿐이고, 앱 이름 글자도 넣지 않음. 시계 아래 캡션도 `CALIBRE VR-01`로 시작 |
| 원산지·인증 표기("Swiss", "Swiss Made", 원산지로서의 "Genève", "COSC", "Chronometer", 각종 인증 마크) | 어떤 원산지·인증 문구도 없음. "코트 드 제네바"는 마감 기법 이름으로 문서에서만 씀 |
| 특정 모델의 상징적인 바늘(메르세데스, 브레게 "폼", 스노플레이크, 캐서드럴, 장갑 낀 손) | 직접 설계한 면 분할 창 모양 바늘 + 야광 홈 |
| 유명 모델의 케이스·크라운 가드·푸셔 모양 | 일반적인 원형 케이스, 크라운 가드 없음, 단순한 원통 푸셔와 크라운 |
| 실제 칼리버의 브리지 배치와 로터 모양 | 배럴 브리지·기어열 브리지·크로노 브리지를 새로 배치, 로터는 터빈 날개 모양 창이 있는 반원(오리지널) |
| 실제 시계 사진·텍스처 | 사진 없음. 매크로 사진처럼 보이는 벨벳 결, 조명, 비네팅과 페를라주, 코트 드 제네바, 선레이, 블루 스크루, 루비는 모두 코드로 그림 |

- 문자판 구성(스몰 세컨드, 30분 카운터, 파워 리저브, 문페이즈, 날짜)은 시계 업계의 일반적인 기능 조합이며, 위치와 모양은 직접 정했습니다.
- 실제 시계 브랜드와의 협업은 정식 라이선스 계약 뒤에만 진행합니다(기획서 6장).

### 시계 케이스 형상 (v1.7.0 단계 사다리)

단계마다 케이스가 달라집니다(스틸 원형, 데코, 쿠션, 토노 스켈레톤, 투르비용). 특정 브랜드를 떠올리게 하는 형상(직사각 탱크형 케이스, 나사가 박힌 사각 베젤, 로마 숫자와 파란 카보숑 용두)은 쓰지 않았고, 이름은 가상의 `VR-01`입니다.

## 8. 엔진룸 테마 (엔진·모터 단면도)

엔진도 제조사마다 고유한 이름과 디자인이 있는 분야라, 엔진룸 테마는 **어떤 실제 엔진이나 모터도 따르지 않도록** 만들었습니다.

| 피한 것 | VE-4T · VE-M1의 처리 |
|---|---|
| 자동차·부품 제조사 이름, 로고, 엠블럼, "Powered by" 배지 | 표기는 모델 코드 `VE-4T`, `VE-M1`과 도면 번호 `DWG VE-4T-100` / `DWG VE-M1-200`뿐이고, 앱 이름 글자도 넣지 않음 |
| 실제 엔진 계열·기술 이름(예: GDi, T-GDi, Smartstream, Theta, Gamma, Nu, Kappa, Lambda, VTEC, EcoBoost, TFSI, Hemi, Boxer, Rotary, SKYACTIV) | 어떤 엔진 계열 이름도 쓰지 않음. 화면의 말은 "흡기, 배기, 터보, 크랭크, 변속기, 인버터"처럼 일반 명사뿐 |
| 유명 엔진의 상징적인 헤드커버 모양·색(예: 붉은 주름 도장) | 매뉴얼 도면식으로 평평하게 칠한 밝은 회색 커버, 일반적인 둥근 사각형 |
| 실제 엔진·모터 사진, 제조사 단면도 | 사진·텍스처 없음. 일반적인 제도 관례(45° 해칭, 번호 풍선, 부품 목록, 표제란)만 쓰고, 보어 75 · 스트로크 79 · 로드 135mm 같은 수치로 직접 계산해 그림 |
| 실제 변속기의 기어비 표, 실제 모터의 극수·슬롯 조합을 그대로 가져오기 | 기어비·감속비·극수는 일반적인 범위에서 직접 정한 값 |
| 차량 경고등·계기판 아이콘(엔진 점검등 등) | 경고등처럼 생긴 그림, 빨간 경고색, "점검·경고·고장" 같은 말을 쓰지 않음(테스트로 칩 문구 확인) |

- 직렬 4기통, DOHC, 터보, 8단 자동변속, 영구자석 동기 모터는 자동차 업계의 일반적인 구성이며, 배치·비율·마감은 직접 정했습니다.
- 실제 자동차 제조사의 엔진을 그리는 협업은 정식 라이선스 계약 뒤에만 진행합니다(기획서 6장).

## 9. 제작 방식

- 그림은 전부 코드(Compose Canvas의 경로·타원·선)로 그립니다: `character/src/main/java/io/vroomi/character/render/` (`VroomiPainter.kt` 공통 리그, `SkinPainter.kt` 친구 15종, `KartPainter.kt` 꼬마차, `WorldPainter.kt` 배경, `calibre/` 칼리버 테마, `engine/` 엔진룸 테마, 그 밖의 테마는 각자의 폴더와 전용 팔레트)
- 내려받은 캐릭터 이미지, 기존 캐릭터를 흉내 낸 AI 생성 이미지를 쓰지 않습니다.
- 앱 아이콘도 같은 형태를 벡터로 직접 그렸습니다: `app/src/main/res/drawable/ic_launcher_foreground.xml`
- 폰트는 시스템 폰트, 효과음은 사용하지 않습니다.

## 10. 테마 팩 7종

모든 그림은 코드로 그렸습니다(이미지 파일, 사진 따라 그리기, 브랜드·로고·유명 캐릭터 없음). 꼬마차와 친구들만 브루미의 세계이고, 나머지 테마는 각자 독립된 세계입니다. 브루미, 친구, 꼬마차, `VROOMI` 글자, 브루미의 금색 별을 빌려 쓰지 않고, 그림 기법은 "리소 인쇄", "동판화"처럼 일반적인 기법 이름으로만 정했습니다(특정 작가나 회사의 화풍을 따르지 않음).

## 11. 8비트 도트 IP (도트 월드 테마)

"옆으로 흐르는 8비트 길"은 장르일 뿐이고, 특정 게임의 캐릭터·사물·화면 구성·소리는 하나도 쓰지 않았습니다. 모든 도트는 코드 안의 문자열 격자나 정수 규칙으로 직접 찍었습니다(이미지 파일, 다른 게임의 스프라이트 따라 그리기 없음).

| 유명 배관공 주인공(콧수염, 글자가 적힌 모자, 멜빵바지), 공주, 탈것 공룡 | 오리지널 주인공: 커다란 바퀴의 네모난 탐사차(34픽셀 너비)와 둥근 헬멧에 바이저만 있는 작은 조종사(12 × 12, 눈·귀·얼굴 없음). 브루미·친구·꼬마차는 이 세계에 나오지 않음 |

## 12. 인터페이스 IP

화면의 품질 목표는 "잘 만든 소비자 소프트웨어"이지만, 특정 회사의 자산이나 그 회사만의 모양은 쓰지 않았습니다.

| 피한 것 | 대신 만든 것 |
|---|---|
| 특정 회사의 시스템 글꼴과 기호 아이콘 세트 | 기기 기본 글꼴을 그대로 씀. 아이콘(닫기, 좌우 화살표, 아래 화살표)은 24단위 격자에 1.9단위 둥근 선으로 코드에서 직접 그림 (`app/.../ui/design/Icons.kt`) |
| 화면 위 가운데의 알약 모양이 실시간 정보로 변하는 부품, 제어 센터식 타일 격자, 특정 회사 모양 그대로의 스위치·분절 버튼·시트 손잡이, 앱 스토어식 카드 배치, 빛을 굴절시키는 유리 가장자리 효과 | 일반적인 카드·시트·분절 선택·반투명 면을 브루미의 토큰으로 그림: 반투명 재질 4종(Thin·Regular·Thick·Chrome, 흐림과 1px 선과 2.5% 입자), 직접 계산한 3차 베지어로 만든 연속 곡률 모서리(`SmoothCornerShape`), 테마에서 빌린 강조색. 스위치는 Material 3 기본 부품 |
| 특정 회사의 시스템 소리와 이름 붙은 진동 패턴 | UI 효과음 없음. 진동은 Android 표준 `HapticFeedbackConstants`(CONTEXT_CLICK, CONFIRM)만, 주차 중에만 |
| 다른 앱의 화면 전환을 그대로 따라 하기 | 테마 열한 개의 입장은 각 테마의 세계에서 나온 움직임으로 새로 설계: 단면 선, 펼쳐지는 해도, 차오르는 물, 태양에서 열리는 원, 4 × 4 순서 디더 등 |
| 문서·코드·커밋에 특정 회사나 제품 이름 쓰기 | 결과는 "정제된", "차분한", "고급스러운"으로만 설명 |

글꼴 파일은 넣지 않았습니다. 기본 글꼴로 충분했고, 넣으려면 오픈 폰트 라이선스 원문 확인·고지·용량 조건을 모두 만족해야 하기 때문입니다.
